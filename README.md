\# Streamlit Planner App



A beginner-friendly planner app built with Python, Streamlit, and SQLite.



\## Features



\- Create, open, rename, and delete plans

\- Default buckets: Backlog, Up next, In progress, Blocked, Completed

\- Add, edit, move, complete, and delete tasks

\- Due date and priority

\- Assignee and labels

\- Checklist items

\- Checklist progress like 2/5

\- Board view

\- Grid view

\- SQLite database storage



\## Tech Stack



\- Python

\- Streamlit

\- SQLite



\## How to Run Locally



```bash

pip install -r requirements.txt

python -m streamlit run app.py
