\# User Stories



\## Completed MVP Stories



\### Story 1: Create a plan



As a user, I can create a plan so that I can organize tasks for a project.



\### Story 2: Open a plan



As a user, I can view and open existing plans.



\### Story 3: Manage plans



As a user, I can rename and delete plans.



\### Story 4: Add tasks



As a user, I can add tasks into buckets.



\### Story 5: Move tasks



As a user, I can move tasks between buckets.



\### Story 6: Edit tasks



As a user, I can edit task title, description, due date, priority, assignee, and labels.



\### Story 7: Delete tasks



As a user, I can delete tasks I no longer need.



\### Story 8: Checklist items



As a user, I can add checklist items and mark them complete.



\### Story 9: Board view



As a user, I can view tasks in bucket columns.



\### Story 10: Grid view



As a user, I can view all tasks in a table.



\## Next Recommended Stories



\### Story 11: Search tasks



As a user, I can search tasks by title, assignee, or label.



\### Story 12: Filter tasks



As a user, I can filter tasks by bucket, priority, status, or assignee.



\### Story 13: Improve task card design



As a user, I can see cleaner and more useful task cards.



\### Story 14: Add dashboard summary



As a user, I can see total tasks, completed tasks, overdue tasks, and high-priority tasks.



\### Story 15: Improve cloud database storage



As a user, I want my data to persist reliably after deployment.
